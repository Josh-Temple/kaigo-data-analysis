# Methodology v0.1

Updated: 2026-10-07

## 1. 原則

分析の再現性と、データが実際に意味している範囲を優先します。

取得成功、スキーマ適合、加工成功、分析上の利用可否は別の状態として扱います。

## 2. データ層

### raw

公式配布物を変更せず保存するローカル領域です。原則Git管理しません。

記録対象:
- source URL
- fetched_at
- source period / snapshot
- SHA-256
- HTTP metadata when available

### staged

文字コード、列名、型、地理コード等を正規化した中間データです。

### curated

分析に必要な粒度へ整えたデータです。元データから再生成可能にします。

### published

公開サイトが読む小さな集計データです。出典と生成時点を一緒に持たせます。

## 3. Source qualification

各データ源について、最低限次を確認します。

- 公式な配布元か
- 対象期間または基準日が明示されているか
- 地理粒度が確認できるか
- 更新頻度が確認できるか
- 二次利用条件が確認できるか
- 必要な列が安定して取得できるか

過去に取得エラーがあっても、それだけで将来の取得を恒久的に失格にはしません。実行時の取得結果とデータ自体の適格性を分離します。

## 4. 事業所データの注意

介護サービス情報公表システムのCSVは「そのスナップショットで掲載されている事業所情報」です。

したがって、

- 前回あり・今回なし = 廃業
- 前回なし・今回あり = 新規開設

とは自動判定しません。

v0.1では「掲載数の増減」「掲載開始候補」「掲載終了候補」として扱います。指定・廃止・休止の確認には別の一次情報が必要です。

## 5. 需給指標の注意

事業所数は供給能力の粗い代理変数です。

同じ1事業所でも、定員、職員数、稼働日、提供地域、利用者構成が異なります。そのため、人口当たり事業所数だけで「不足」「過剰」と判定しません。

## 6. 人口

将来人口は推計値です。将来の介護利用量そのものではありません。

初期分析では、75歳以上人口などの人口構成変化を、サービス供給を検討する背景変数として使います。

## 7. 人流

国土交通省が公開する全国1kmメッシュ人流データは2019-2021年の位置情報由来データです。

現在の地域状況や高齢者の移動を直接表すものとして使いません。必要な場合のみ、過去の地域活動・アクセス環境を考える補助情報として扱います。

## 8. Missingness

欠損値はゼロに置換しません。次を区別します。

- true zero
- not reported
- not applicable
- suppressed / masked
- parse failure
- unknown

元データで区別できない場合は unknown とします。

## 9. 地理結合

自治体コード、保険者コード、メッシュコードを主キーとして使用します。

名称だけでの結合は原則行いません。自治体再編・広域連合・一部事務組合などで対応が一対一でない場合は、明示的な対応表を作ります。

## 10. Public interpretation

公開サイトでは、観察結果と解釈を分けます。

例:

観察: 75歳以上人口1万人当たりの訪問介護事業所掲載数が比較対象より少ない。

解釈: 供給が相対的に薄い可能性はある。

非許容: 訪問介護が不足している、とこの指標だけで断定する。
