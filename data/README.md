# Data directories

このリポジトリでは、生データと公開用集計データを分離します。

## raw/

公式配布物の取得先。Git管理しません。

## staged/

列名・型・文字コード・地理コード等を正規化した中間データ。Git管理しません。

## curated/

分析用に粒度をそろえたデータ。大容量ファイルはGit管理しません。

## published/

公開サイトが読む小さな集計データの生成先。実データ公開を始める時点で、出典・生成日時・スキーマを含むmanifestを必須にします。

データをGitへ追加する場合は、元データから再生成可能か、ライセンス上問題がないか、個人情報を含まないかを確認してください。
