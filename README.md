# kaigo-data-analysis

日本の介護について、公開データから地域差・需給・事業所の変化を分析するためのプロジェクトです。

## 目的

制度情報を扱う kaigo-rules と役割を分け、このリポジトリでは「地域で何が起きているか」をデータから確認します。

初期の問いは次の3つです。

1. 高齢者人口・要介護認定者数に対して、介護サービスの供給は地域ごとにどう違うか。
2. 介護サービス事業所の掲載状況は時系列でどう変化しているか。
3. 将来人口の変化に対して、現在のサービス配置はどこで相対的に薄くなる可能性があるか。

## 現在の段階

v0.1 foundation。2026-10-07 時点で、公式データ源の台帳、指標定義、再現可能な検証の骨格、公開画面の最小構成を作っています。

生データは原則としてGitへコミットしません。取得元、取得時点、ハッシュ、加工手順を記録し、公開用には再生成できる集計データだけを使用する方針です。

### First validated source probe

訪問介護の公式CSVについて、2025-12-31 と 2026-06-30 の2時点をGitHub Actionsから実取得し、スキーマ・必須列・事業所番号の一意性・SHA-256・掲載差分を確認しました。

- 2025-12-31: 35,191行 / 35,191事業所番号
- 2026-06-30: 35,166行 / 35,166事業所番号
- 純差分: -25
- 掲載開始候補: 1,276
- 掲載終了候補: 1,301
- 自治体別の純増減が0でない地域: 678

これは掲載状態の比較であり、開設・廃業・供給能力の増減を直接意味しません。長期証跡は `data/source-audits/mhlw-visit-care-2025-12_to_2026-06.json` に固定しています。

### Demand denominator qualification

厚生労働省「介護保険事業状況報告（暫定）令和8年6月分」の保険者別XLSXも実取得・検証しました。

- 第1号被保険者数: 1,574行、全国合計 35,874,845人
- 75歳以上: 全国合計 21,304,752人
- 第1号被保険者の要介護・要支援認定者: 全国合計 7,290,395人
- 再計算した認定率: 20.3217%
- 2表の `都道府県 + 保険者名` キー: 完全一致
- 各表の行合計: XLSX内の全国計と一致

ただし、月報XLSXの検証済み列には保険者コードがありません。市区町村別事業所データへの名称結合は禁止し、公式の保険者―市区町村対応を取得するまで地域別需給比率の公開を止めます。詳細は `methodology/GEOGRAPHY_JOIN.md` を参照してください。

### Conservative geography crosswalk

J-LIS「地方公共団体コード住所」の47都道府県ページと月報1,574保険者を、`都道府県 + 保険者名` の完全一致だけで照合しました。

- 安全に結合: 1,531保険者（97.27%）
- blocked: 43保険者
  - 広域連合 25
  - 行政組合・介護保険組合等 13
  - 現行J-LIS団体名との表記差 5

blocked行は市区町村へ推測配賦しません。監査結果は `data/source-audits/insurer-municipality-crosswalk-2026-06.json` に固定しています。

### Demand-normalized visit-care pilot

安全に結合できた1,531保険者だけを使い、2026年6月末の訪問介護掲載事業所数を第1号被保険者の75歳以上人口で正規化しました。

- 75歳以上人口coverage: 95.46%
- 1万人あたり掲載事業所数の中央値: 11.94
- 横浜市: 75歳以上568,509人 / 掲載847事業所 / 1万人あたり14.90
- 政令指定都市はJ-LISの行政区コードを市単位へ集約

これは掲載事業所数の観察であり、定員・職員数・稼働量・利用可能量を表しません。不足・過剰の判定には使いません。

- 監査: `data/analysis-audits/visit-care-demand-normalized-pilot-2026-06.json`
- 公開用データ: `docs/data/visit-care-pilot.json`
- 公開画面: `docs/visit-care.html`

## 初期データ源

- 厚生労働省「介護サービス情報公表システム」事業所オープンデータ
- 厚生労働省「介護保険事業状況報告」
- 国土交通省「250mメッシュ別将来推計人口データ（R6国政局推計）」
- 国土交通省「全国の人流データ」：補助的・過去期間の文脈用。現在の介護需要の代理にはしない

詳細と確認日は config/data_sources.json を参照してください。

## 初期指標

- サービス別事業所数
- 事業所数 / 75歳以上人口
- 要介護・要支援認定率
- 事業所掲載数のスナップショット間増減
- 将来75歳以上人口の変化

「事業所数」は供給能力そのものではありません。また、公開CSVから掲載がなくなったことを廃業と同一視しません。指標の限界は config/metrics.json と methodology/METHODOLOGY.md に明示します。

## Repository structure

- config/ : データ源と指標の正本
- data/ : ローカル取得・加工・公開データの境界
- methodology/ : 分析範囲、解釈、品質管理
- scripts/ : 台帳検証・取得・加工
- docs/ : 公開サイト
- .github/workflows/ : 再現性チェック

## Validation

Python 3.11+ で次を実行します。

    python scripts/validate_registry.py

データ源IDの重複、必須項目、指標から未登録データ源への参照を検査します。
