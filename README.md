# kaigo-data-analysis

日本の介護について、公開データから地域差・需給・事業所の変化を分析するためのプロジェクトです。

## 目的

制度情報を扱う kaigo-rules と役割を分け、このリポジトリでは「地域で何が起きているか」をデータから確認します。

初期の問いは次の3つです。

1. 高齢者人口・要介護認定者数に対して、介護サービスの供給は地域ごとにどう違うか。
2. 介護サービス事業所の掲載状況は時系列でどう変化しているか。
3. 将来人口の変化に対して、現在のサービス配置はどこで相対的に薄くなる可能性があるか。

## 現在の段階

v0.1 foundation。2026-10-07 時点で、公式データ源の台帳、指標定義、再現可能な検証の骨格、公開画面の最小構成を作っています。

生データは原則としてGitへコミットしません。取得元、取得時点、ハッシュ、加工手順を記録し、公開用には再生成できる集計データだけを使用する方針です。

### First validated source probe

訪問介護の公式CSVについて、2025-12-31 と 2026-06-30 の2時点をGitHub Actionsから実取得し、スキーマ・必須列・事業所番号の一意性・SHA-256・掲載差分を確認しました。

- 2025-12-31: 35,191行 / 35,191事業所番号
- 2026-06-30: 35,166行 / 35,166事業所番号
- 純差分: -25
- 掲載開始候補: 1,276
- 掲載終了候補: 1,301
- 自治体別の純増減が0でない地域: 678

これは掲載状態の比較であり、開設・廃業・供給能力の増減を直接意味しません。長期証跡は `data/source-audits/mhlw-visit-care-2025-12_to_2026-06.json` に固定しています。

## 初期データ源

- 厚生労働省「介護サービス情報公表システム」事業所オープンデータ
- 厚生労働省「介護保険事業状況報告」
- 国土交通省「250mメッシュ別将来推計人口データ（R6国政局推計）」
- 国土交通省「全国の人流データ」：補助的・過去期間の文脈用。現在の介護需要の代理にはしない

詳細と確認日は config/data_sources.json を参照してください。

## 初期指標

- サービス別事業所数
- 事業所数 / 75歳以上人口
- 要介護・要支援認定率
- 事業所掲載数のスナップショット間増減
- 将来75歳以上人口の変化

「事業所数」は供給能力そのものではありません。また、公開CSVから掲載がなくなったことを廃業と同一視しません。指標の限界は config/metrics.json と methodology/METHODOLOGY.md に明示します。

## Repository structure

- config/ : データ源と指標の正本
- data/ : ローカル取得・加工・公開データの境界
- methodology/ : 分析範囲、解釈、品質管理
- scripts/ : 台帳検証・取得・加工
- docs/ : 公開サイト
- .github/workflows/ : 再現性チェック

## Validation

Python 3.11+ で次を実行します。

    python scripts/validate_registry.py

データ源IDの重複、必須項目、指標から未登録データ源への参照を検査します。
