KAIGO DATA ANALYSIS / v0.1

地域の介護を、
公開データから読む。

人口、要介護認定、介護サービス事業所、将来人口。別々に公開されている情報を、出典と限界を残したまま結びます。

現在はデータ源と分析方法を固定している段階です。実データの公開は、取得・スキーマ・地理結合の検証後に開始します。

01

調べたいこと

  1. A

    介護サービスの地域差

    高齢者人口や認定者数に対して、各サービスの事業所掲載数は地域ごとにどう違うか。

  2. B

    事業所掲載状況の変化

    半年ごとの公式スナップショットを比較し、サービス供給の変化を観察する。

  3. C

    将来人口との関係

    人口構成が変わる地域で、現在のサービス配置がどのように見えるかを確認する。

人流は現在の高齢者の移動や介護需要の代理には使いません。

03

数値を断定に変えない

事業所数が少ない。それだけで「介護が不足している」とは言いません。

定員、職員数、稼働量、提供地域、利用者構成は事業所ごとに異なります。公開画面では、観察できた事実、そこから考えられること、データだけでは分からないことを分けて示します。

04
